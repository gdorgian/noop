# Noop Aura 10.5.0

Noop Aura 10.5.0 is the iOS-only Aura release built on `ryanbr/noop` v10.5.0. Its marketing version
matches upstream; build 230 and the `-aura.230` tag identify this fork's artifact.

## Aura on iPhone

- The installed app, widget and release are named **Noop Aura**.
- The persistent navigation is **Today · Trends · + · Rest · You**. The centre `+` opens the existing
  real Live HR, workout, journal and breathing actions; it is not a navigation tab.
- Today shows the canonical Rest composite, morning Charge, today's Effort, measured strap heart rate
  and recorded nightly signals. The breathing prompt never changes the heart-rate number.
- Dark appearance is fixed for this Aura release. iOS accessibility contrast and Reduce Motion are
  still respected.
- Planned destinations remain visible with explicit **Coming Soon** states. They show no substitute or
  preview values; existing underlying tools remain available where the screen says so.

## Measurement and copy audit

- Recovery state labels now use the same 34/67 bands as the canonical Charge scorer instead of a second
  UI-only threshold set.
- The Rest tile no longer compares sleep duration with an arbitrary eight-hour bar; it uses the stored
  0–100 Rest composite and keeps duration as supporting evidence.
- Body Age driver effects use the model's overlap correction and hazard-to-years conversion. The UI no
  longer presents the model's five-year display band as validated uncertainty or calls one factor the
  cheapest to change.
- Trend comparisons need at least seven recorded values, and a personal-normal band needs fourteen.
  Missing Effort days are no longer rendered as zero.
- Coach-provider privacy copy now covers consented provider requests and opt-in background summaries.

## Respiratory-rate investigation

- WHOOP 5 v18 R-R ticks continue to convert to milliseconds at parse time.
- The log's units evidence now searches lags from −5 to +5 seconds instead of requiring live and
  historical copies to share the exact stored second.
- Each night reports raw and selected transport counts, including live rows suppressed when a historical
  copy wins, plus the exact rejection reason when respiratory rate remains unavailable.
- App version, build and commit SHA are written into diagnostic logs so a field capture can be tied to
  the exact artifact.

These diagnostics strengthen the evidence for the transport de-duplication fix, but do not turn sparse
or low-integrity R-R data into a breathing estimate. The app continues to leave respiratory rate blank
when its quality gates do not pass.

## Upstream 10.5.0

This release also includes upstream training load (CTL, ATL and form), VO₂max estimation with disclosed
method, Apple Health workout write-back and hourly step import, Oura provenance fixes, power-saving
controls and Polar PMD protocol groundwork. It does not expose Polar PMD as an app-level sensor source.

Noop Aura is an independent wellness app, not a medical device. Its estimates are informational and are
not diagnoses or treatment advice.
