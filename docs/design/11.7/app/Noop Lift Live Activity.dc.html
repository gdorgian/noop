WAVE 4C The lift live activity one session, four presentations, four states

Read at a glance, mid-set, from a phone on the floor.

All four presentations read the same live session as the bar on lift-live, and carry the same four slots in the same order: what is running, the exercise, the clock, the set. What changes between them is only how much of that survives the space. The Lock Screen card was settled in wave 2; the three Dynamic Island presentations are this sheet's work, and paused is the state the wave-2 matrix was missing.

TWO INKS, NO ALPHA #17A2E6 while the set is worked, #C6CEC9 while the clock runs down, one opaque value each. Ready keeps the working ink because the next set is the thing to act on; paused drops to #7F8A85, the app's disabled ink, because nothing is counting. Never amber, and never a translucent tint — this sits on somebody's photograph.
THE ACTIVITY CARRIES NO CONTROLS No Pause, no Next set, no Finish. Pause lives on lift-live and nowhere else, exactly as the bar has none — a control whose consequence you cannot see is not a control, and a Finish button an inch from a Lock Screen swipe is a lost session. Tapping anywhere opens lift-live, which is where every one of those decisions is already drawn.

FOR THE BUILD Four things to hold to
One source. All four presentations and the in-app bar read the same live session object. If the bar says ready, the island says ready in the same tick — they are not two clocks that happen to agree. Paused freezes, it does not hide. The clock stays on screen at its held value in disabled ink. Hiding it reads as a reset, and a wearer who thinks the set timer reset will redo the set. The numbers slot is absent, never a dash pair. Where neither reps nor weight is known the element is not rendered — the status line simply takes the width. Six em dashes are the thing this whole act refuses. Truncate the exercise, never the clock. "Incline dumbbell press" at 23 pt overruns 364 pt; the name takes the ellipsis and the clock and the set counter keep their width at every size.
