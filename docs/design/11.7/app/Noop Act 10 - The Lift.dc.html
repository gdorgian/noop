Eight screens, drawn around a program line that is nothing but a name.

Act 10 hangs off Today, the way Act 3 does — lifting is an effort, not a place to browse. Every target on a line is optional and most lines carry none, so the bare line is the default drawing here and the fully-targeted one is the variant. Switch screen and each screen’s state in the panel; the route id is under each title below. The ninth item in the picker is the Lock Screen activity, which is not a screen of the act.

W2 · 1
lift-live — the working screen Six states, and bare is the one to judge it on: no targets, no prefilled numbers, no em-dashes standing in for six fields nobody set. Running shows the decorated case with the progression reason beside the exercise, because that sentence is the only reason the prefilled weight is not a mystery. Every control is 44 pt or more and the pad is one tap from the number keyboard. last is the drop set expanding mid-session: one planned line became three rows and the screen grew.
W2 · 2
lift-library — programs you keep List, open, start, archive, and the two doors in. Archived programs are shown at 38 % and read-only rather than hidden — they still own their sessions. The collision state is the refusal: a cardio session is running, so starting a lift is declined rather than silently ending it. Three parts, no red, no End button, and neither action is styled as the safe one.
W2 · 3
lift-program — the editor, and the six modes Lines reorder by drag; a line with no targets reads just the exercise in quiet type rather than a row of blanks. The expanded editor shows all six optional targets with not set where they are unset. Underneath, the block engineering needs: six measurement modes, one row — weight × reps, bodyweight reps, duration, weighted, assisted, reps only, with the catalogue counts and exactly how each renders.
W2 · 4
lift-detail — read-only, and priced in Act 1’s currency Four figures, then every exercise with its sets as pills, warm-ups folded away with the count stated. noRpe shows the absent case: an em-dash and a reason, never a zero. noProgram is the session logged without one — it is not an error and reads as an ordinary Tuesday. The cost card is Act 3’s, unchanged: a lift is not a different kind of effort.
W2 · 5
lift-edit — correcting it afterwards A deleted set stays visible, struck through, with undo until you save; the working-set total above restates as you go so the figure and the rows can never disagree. committed is green in place for two seconds, no toast. One line says the boundary: what you logged is editable, what the strap measured is not.
W2 · 6
lift-import — file or key, and the word is adds Four states. Reading renders the card at final size with real counts rather than a spinner. failed is a three-part refusal — what happened, why, what you can do instead — and not red. Nowhere on this screen or the next does the word sync, update or replace appear: import adds, and running it twice does not double anything.
W2 · 7
lift-review — summary and commit, because the file cannot do better Your answer changed this screen. With no per-set provenance there is nothing honest to tick, so it states what it made of the file — sessions, span, matched and unmatched names, warm-ups folded — and says plainly why there are no checkboxes. partial names every skipped session and its reason; nothing is a refusal, not an empty list.
W2 · 8
lift-muscles — credited sets, seven regions, thirty-three muscles Drawn on your projection: 1.0 primary, 0.5 secondary, stabilisers zero — so the unit is credited sets and the screen says so at the top. Group headers come from the region derivation, not the parent chain, so there are no orphans and no invented parents. calibrating withholds the figures and shows the session count instead, per rule 13; absent is one sentence. Recovery reads in lavender, never amber — a worked muscle is not a warning.
W2 · BAR
One bar, two contents Same 46 pt bar, same four slots in the same order. The middle two change: the exercise name replaces the workout name, the clock counts the set or the rest rather than the session, and the set counter takes the heart rate’s place. Working is the running blue; resting is neutral, not amber — rest is not a thing you must act on, and amber in this app means exactly that. The third state is drawn now too — ready, where the rest has run out but the next set has not started. It is the state a drawing usually forgets, and the bar says Ready rather than holding a countdown at zero.
W2 · LOCK
The Lock Screen activity — chosen where it is read You asked for the neutral value picked on the Lock Screen rather than on the sheet, so it is drawn there: one card, on a dark ground, at size. Working #17A2E6. Resting #C6CEC9 — the app's secondary ink, opaque, because a low-alpha white does not survive a wallpaper. One value per state, dot and figure together, which is the shape your one line already has. Slots read in the bar's order and the Lock Screen keeps the two fields the bar has no room for: the set's numbers and the session's progress. noDetail is your empty case — neither reps nor weight known, so the slot is absent rather than blank.
The four doors, and the tab

Act 10 lights Today — your recommendation, taken. In: effort/session → Swap → a lift; the + sheet → Start a lift; today’s session card when it is a lift; and a plumbing/history row with an identity. Route ids are prefixed — lift-live, lift-library, lift-program, lift-detail, lift-edit, lift-import, lift-review, lift-muscles — also taken, and they read the same way in QA as they do here. Your three shell choices stand exactly as you made them: Today lights, + opens lift-library, and the ambient stays aura blue.

Answered: the two values the widget needs

The Lock Screen activity is green through a set and amber through the rest. Green means done, written in this palette and amber means something needs you; a set in progress is neither. Both surfaces read aura blue while the set is worked and neutral while the clock runs down. The two values are #17A2E6 working and #C6CEC9 resting — one each, so the widget's one line stays one line. Move the palette into the shared package however suits you; the values are the decision, not the plumbing.

Not drawn, on purpose

No demo loop on the exercise: the catalogue ships no media and the licence does not cover it, so lift-detail is built around the text instructions. The credit is one line on the session, not a field on each exercise: Noop does not credit Noop, so the built-in and the your-own cases render nothing at all. No second unit switch. No weekly set target. And no exercise-confidence chip per row — the mapping’s provenance is stated once, on muscles, where it changes what a number means.

Pause, and what it stops

Yes, the bar has a pause, and it is the one on lift-live — not a second control. It stops both clocks, the set clock and the rest countdown, and holds the part-typed set. It does not mean I have left the gym: nothing is ended, nothing is written, and the session is still owned above the tab bar. Picking it up resumes both clocks from where they stopped — rest does not restart, because a rest you already took is time that passed.
