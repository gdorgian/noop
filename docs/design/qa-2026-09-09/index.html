Read this before filing anything

Two rig faults were found and fixed before any screen was judged. (1) The prototype phone sits at y=103 with height 874 in a 956-tall viewport, so its last 21 px fell below the fold and captured as page background — this alone inflated act3-ready to MAE 25.92; it is 7.26 once corrected. (2) The simulator clock was live. Both are fixed in the numbers below. Depth is honest: the three screens in “Findings” were read frame by frame; the remaining 47 are automated triage with evidence attached for review.

Systematic findings

Demo seed does not reproduce the prototype’s fixtures

Confirmed on act2-today: charge is 44 in the prototype and 56 in the build from the same starting value and the same day window. Any screen whose copy is computed from a value will read as a copy defect when it is really a seed difference. This was the risk raised before the run and it has materialised; it needs settling before copy findings on numeric screens can be trusted.

Status bar is matched, not ignored

The prototype’s 9:41 is [proto]-tagged. Rather than let a wrong clock pollute fifty scores, the simulator status bar was overridden to 9:41 / wifi / 4 bars / 100% discharging. MAE is reported both full-frame and body-only (rows 54–874).

Eight screens carry real vertical drift

Offsets of ±6–12 px. Where the residual falls after shifting (act8-labs +12 → 2.74, act3-live +8 → 1.90, act3-intervals +6 → 1.84) the screen is correct but displaced. Where it stays high (act5-data −12 → 15.59, act8-review +6 → 15.20) the content itself differs.

Fifteen spec screens have no route

54 of the spec’s 69 screens exist as NoopRoute cases. The 15 below were found twice by independent methods — diffing the enum, and mapping prototype labels to spec headings — with the same result each time.

Findings — read in detail

act8-review — Review a photo

Typography / copy

Chip reads READ, NOT MEASURED (uppercase, tracked) in the design; the build renders read, not measured lowercase. RULES §1 puts +1.2 pt tracking on uppercase captions — a lowercase chip has neither the case nor the tracking.

Fixture content

Body copy is rewritten. Design: “Each row shows the strip of the page it came from — check the number against it, fix it if the read is wrong…”. Build: “Where a strip is shown, it is the part of the page the number was read from. Check each number against your report…”. RULES tags [static] copy as final; rewording is a bug of the same class as a wrong hex.

Behaviour

Footer sub-line differs. Design: “Confirm or fix a row — Save does nothing until then”, which is CLOSURE §3’s dead-button requirement stated in words. Build: “4 still to check · 0 discarded”, a progress count that does not say what would make Save live.

Geometry

+6 px vertical drift, residual 15.2 — the residual stays high after shifting, so this is divergent content and not a displaced copy of the same screen.

act5-data — Data & privacy

Routing — highest severity

The build’s data route renders import’s screen. Design shows spec 5.9 “Data and permissions” — What the strap records / Where it lives / Apple Health + Strava toggles. The build shows spec 5.17 “Bring your history in” — the blush drop target and “Choose a file or folder”.

Routing consequence

This also explains import appearing in the wiring-gap list: it has no NoopRoute case because it has taken over data’s. Two spec screens are collapsed onto one route, so the spec’s data screen — including the Delete destructive action and its required confirmation (5.9 §3) — has no route at all.

Evidence

Best-fit vertical offset −12 px with residual 15.59. A residual that stays high at every offset means the two frames are not the same screen; contrast act8-labs, which shifts 12 px but drops to residual 2.74.

act2-today — Today

Fixture content — blocks copy review

Charge diverges: design “you have 44 left” / headline “Just under half left”; build “you have 56 left” / “Enough for the evening”. Both start from “woke with 92” and both render the same window 06:41 → 14:20, so this is a computed-value divergence, not a clock difference. The headline is driven off the value, so the copy cannot be judged until the seeds agree.

Not a defect

The orb differs (67 / OUT vs 73 / IN) because the box-breathing pacer is live; the two captures are different phases of the same animation. Recorded here so it is not filed as a defect.

Materials

Gauge tick marks read pale/white in the design and aura-blue in the build. Partly confounded by the charge divergence above, since fill state may be charge-dependent — needs re-checking once seeds match.

Geometry

Vertical offset 0 px. Header, cards and tab bar align.

Wiring gaps — spec screen with no NoopRoute case

Found independently twice, same 15 both times. import appears here because it occupies data’s route (see act5-data).

Method

Prototype captured through headless Brave over CDP at a 1470×956 window, locating the visible element whose bounding rect measures exactly 402×874 by hit-test rather than hardcoded coordinates, captured with Page.captureScreenshot and captureBeyondViewport. Navigation by clicking the visible Act label then the visible screen label by exact text, filtered to data-dc-tpl 20 and 28 so hidden and zero-sized matches are excluded, 650–750 ms settle. iOS captured with simctl at 1206×2622 and reduced with sips -z 874 402, launched per route with --demo-seed --noop-route. Comparison is Pillow blend / difference / MAE, plus 16 horizontal bands, 8 vertical columns, and a ±12 px luminance cross-correlation for drift. The same-position flip is the acceptance test; MAE is diagnostic only.
