# Screenshot provenance

These images are native iOS Simulator captures of the 11.7 Aura interface at the design comparison size of 402 × 874 points. They use `--demo-seed` in a Debug build to show the designer's example person and demonstrate appearance. The example measurements are not Release data, and the images are not evidence that every data-driven feature is complete or hardware-verified.

- `today.png`, `rest.png`, `trends.png`, `you.png`: the four screens on the project page.
- `showcase/`: a cover image and four themed images (goals and bloodwork, ages and heart, breathing
  and training, the long view), each four screens on the app's background, made for the project page
  and the community post. 1600 × 900.
- `screens/`: 27 individual screens, named by what they show (for example `goal-journey.png`,
  `bloodwork-labs.png`, `svea-coach.png`), captured the same way on 26 September 2026.

Some screens show features the 11.7.0 release does not provide yet, because the Debug demo renders
the full design: intraday Charge, the year so far, pace of aging and the lights-out plan. See
[`docs/aura`](../../aura/README.md) for what is and is not wired.
